# CodeSphere Emirates website

A responsive, single-page website built with plain HTML, CSS, and JavaScript. No paid tools, packages, or installation required.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing
Open `index.html` in a text editor and find these lines near the bottom:
- `const LINKEDIN_PAGE_URL = "";`
- `const CONTACT_EMAIL = "";`

Paste your actual LinkedIn Page URL and the email address you want visitors to use between the quotation marks.

## Publish free with GitHub Pages
1. Sign in or create a free GitHub account.
2. Create a public repository named `codesphere-emirates`.
3. Upload `index.html` to the repository's root.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for GitHub to publish the site; its Pages settings will show the live URL.

The site is ready as a starter website. It does not include a backend, member database, or working contact form.
